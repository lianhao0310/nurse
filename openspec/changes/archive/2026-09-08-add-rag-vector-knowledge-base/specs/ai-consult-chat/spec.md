## MODIFIED Requirements

### Requirement: 倪海厦中医人设
系统 SHALL 使用"精简核心规则（约 500 tokens）+ RAG 动态检索片段"拼接构建的 system message 作为 AI 默认人设，使 AI 以倪海厦视角进行六经辨证、经方建议、饮食禁忌等回复。精简核心规则保留六经辨证总纲与回复要求等核心框架，RAG 检索片段根据用户问题动态注入最相关的经方、药性、临床心法等知识。

#### Scenario: 中医辨证回复
- **WHEN** 用户描述症状（如"怕冷无汗脖子疼"）
- **THEN** 系统将症状向量化检索知识库，拼接精简核心规则与检索片段构建 system message，AI 以倪师口吻回复辨证结果，包含六经归属、病机分析、方剂建议（不出剂量）、饮食禁忌等

#### Scenario: 非中医问题也可回答
- **WHEN** 用户询问一般健康问题
- **THEN** AI 结合中医视角给出回复，但不拒绝非中医问题

#### Scenario: RAG 不可用降级回复
- **WHEN** RAG 知识库初始化失败或检索不可用
- **THEN** 系统仅使用精简核心规则作为 system message，AI 仍能以倪师口吻回复，但知识覆盖范围受限
